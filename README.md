# Statistical Modelling of Customer Purchasing Patterns

## Overview

This project explores customer purchasing patterns through statistical modelling and probability simulations, using Negative Binomial Distribution (NBD) and Pareto models.

The research focuses on probability distribution analysis, parameter estimation, and mathematical modelling to investigate customer purchasing frequency and behavior.

## Objectives

* Apply statistical probability models to customer purchasing patterns.
* Estimate model parameters using NBD and Pareto distributions.
* Develop Python-based probability simulations.
* Investigate purchasing frequency and behavioral patterns.
* Compare modelling approaches and their results.

## Methodology

The project involved:

* Probability distribution analysis.
* Statistical parameter estimation.
* Negative Binomial Distribution (NBD) modelling.
* Pareto modelling.
* Python-based probability simulations.
* Analysis and interpretation of model outputs.

## Repository Structure

* `python/`: Python scripts for statistical modelling and simulations.
* `data/`: Sample or anonymized input datasets.
* `results/`: Model outputs and analysis results.
* `figures/`: Visualizations generated during the project.
